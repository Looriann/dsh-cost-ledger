# 发布教程（零基础版）

> 这份文档是写给你自己的。照着从上往下点，别跳步。
> 全程两个工具：**PowerShell**（敲命令）和 **GitHub Desktop**（点鼠标）。
> 需要敲命令的地方我都写了完整命令，复制粘贴即可。

---

## 0. 先分清四个「名字」

改名前必须知道你在改哪个，否则会改错地方。

| 名字 | 当前值 | 在哪改 | 改了会怎样 |
|---|---|---|---|
| **文件夹名** | `DSH_cost` | 资源管理器里重命名 | 只影响你自己，`link:` 安装的路径要重新加一次 |
| **GitHub 仓库名** | `dsh-cost-ledger`（还没建） | GitHub Desktop 发布时填 | 决定网址 `github.com/你的账号/dsh-cost-ledger` |
| **npm 包名** | `@looriann/dsh-cost-ledger` | `npm run rename`（见第 2 节） | 商场里搜到的名字、`dsh plugin add` 用它 |
| **插件 ID** | `cost-ledger` | `cordis.patch.yml` 的 `id:` | ⛔ **不要改**，改了已装的插件会变成孤儿条目 |

标签页上显示的「费用」写在 `lib/client.js` 的 `label: () => "费用"`，属于**界面文案**，想改成「账单」「花费」都可以，不影响任何功能。

## 1. 先确认你的两个账号名

改名只有一种情况需要做：**你的 GitHub 用户名或 npm 用户名不是 `Looriann`**。

### 查 GitHub 账号名

1. 打开 GitHub Desktop
2. 看右上角头像旁边的名字，或者 `File → Options → Accounts`（Mac 是 `GitHub Desktop → Settings`）
3. 那个名字就是你的 GitHub 用户名

### 查 npm 用户名

1. 打开 <https://www.npmjs.com> 并登录
2. 右上角头像 → 菜单第一行就是你的用户名（也可能是组织名）

> 两个都叫 `Looriann`？**跳过第 2 节**，直接去第 3 节。
> 任意一个不一样，就往下做第 2 节。

## 2. 改名

### 2.1 一条命令改三个关键位置

打开 PowerShell，进入项目文件夹：

```powershell
cd C:\Users\Lenovo\Desktop\DSH_project\DSH_cost
```

先看一眼会改什么（不会真的改）：

```powershell
npm run rename -- --dry "@你的npm用户名/dsh-cost-ledger"
```

确认没问题，去掉 `--dry` 真的改：

```powershell
npm run rename -- "@你的npm用户名/dsh-cost-ledger"
```

它会输出：

```
包名：@looriann/dsh-cost-ledger  →  @你的名字/dsh-cost-ledger
  package.json       name
  cordis.patch.yml   name
  lib/client.js      __ModuleLoader__ id
```

### 为什么必须是这三个地方？

这三个值**必须完全一致**，否则插件装不上或者标签页不出现：

- `package.json` 的 `name` → npm 用这个名字发布，DSH 用这个名字安装
- `cordis.patch.yml` 的 `name` → DSH 启动时按这个名字去 `node_modules` 找包
- `lib/client.js` 的 `__ModuleLoader__` 的 `id` → 浏览器那半边注册模块时用的 key

### 2.2 手动改剩下提到名字的地方

改名脚本**故意不碰**作者名和网址（因为仓库名和包名是两件事，脚本猜不出来）。用这条命令把它们全找出来：

```powershell
git grep -n -i "looriann"
```

会列出这些位置，逐个改成你自己的：

| 文件 | 改什么 |
|---|---|
| `package.json` | `author.name`、`author.url`、`repository.url`、`homepage`、`bugs.url` |
| `LICENSE` | 第一段 `Copyright (c) 2026 Looriann` |
| `README.md` | 安装命令里的包名、最后一行 `© 2026 Looriann` |
| `CONTRIBUTING.md` | `git clone https://github.com/Looriann/...` |
| `cordis.patch.yml` | 第 11 行注释里的安装命令（脚本只改 `name:`，注释要自己改） |
| `CHANGELOG.md` | 一般不用改 |

> 小技巧：如果只是 GitHub 名字不同、npm 名字一样，那只需改 `repository / homepage / bugs / author` 这四处网址和名字，包名不用动。

### 2.3 改完立刻验证

```powershell
npm test
```

必须看到这两行（一项都不能红）：

```
全部通过（22 项）
冒烟通过
```

再确认三个名字真的对齐了：

```powershell
node -e "const p=require('./package.json');console.log('package.json:',p.name)"
Select-String -Path cordis.patch.yml -Pattern 'name:'
Select-String -Path lib\client.js -Pattern '__ModuleLoader__' -Context 0,1
```

三处打印出来的名字要一模一样。

### 2.4 之前装过旧版怎么办

包名一变，你之前 `link:` 装的那份会变成孤儿条目。卸掉重装（**这只影响你本机，不动你的账本数据**）：

```powershell
& "D:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove dsh-cost-ledger
& "D:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add link:C:\Users\Lenovo\Desktop\DSH_project\DSH_cost
```

> 卸载只删插件注册，`~/.dsh/cost-ledger/` 里的账本和价目表都还在。

逐条打勾，缺一条都可能翻车：

- [ ] **`npm test` 全绿**（22 + 10 项）
- [ ] **包名没被占**：浏览器打开 `https://registry.npmjs.org/@你的名字%2Fdsh-cost-ledger`，看到 `404` 才是好的（`200` 说明已存在）
- [ ] **名字统一**：`git grep -n -i "looriann"` 里剩下的都是你想要的
- [ ] **截图**：把「费用」标签页截图存成 `docs/screenshot.png`，再把 `README.md` 里那段被 `<!-- -->` 包住的 `<img>` 取消注释
- [ ] **没有隐私文件**：`git status` 里不该出现 `.env`、`node_modules`、账本文件

## 4. 用 GitHub Desktop 发布

### 4.1 添加本地仓库

1. 打开 GitHub Desktop
2. 菜单 `File` → `Add local repository…`
3. 点 `Choose…`，选中文件夹 **`C:\Users\Lenovo\Desktop\DSH_project\DSH_cost`**
   ⚠️ 选 **DSH_cost 本身**，不要选它的父目录 `DSH_project`，也不要选里面的 `.git`
4. 点 `Add Repository`

项目里已经有 `.git` 和一次提交，所以左侧会出现仓库，中间显示 "No local changes"。

如果它反而提示 *"This directory does not appear to be a Git repository"*，说明你选错文件夹了，回到第 3 步重选。

### 4.2 发布到 GitHub

点右上角蓝色的 **`Publish repository`** 按钮，然后：

| 字段 | 填什么 |
|---|---|
| **Name** | `dsh-cost-ledger`（不加 @，仓库名不带作用域） |
| **Description** | `DSH 插件｜会认服务商的 token 费用账本：百炼、DeepSeek、Kimi、GLM 谁家的价都能查，界面照着 DeepSeek 官方控制台做。` |
| **Keep this code private** | ⛔ **取消勾选**（要公开，商场和用户才能看到） |
| **Organization** | 选 `None`（除非你有组织） |

点 `Publish repository`，等几秒，按钮位置会变成 `Fetch origin` / `Push origin`。

### 4.3 发布成功后补两件事（在网页上做）

点菜单 `Repository` → `View on GitHub`（或 `Ctrl+Shift+G`）打开仓库页面。

**① 加简介和话题**

仓库首页右侧 `About` 那一栏，点旁边的 **齿轮图标**：

- `Description`：填上面那句介绍
- `Website`：留空或填你的 README 地址
- `Topics`：一个一个加（回车确认）
  ```
  dsh  dsh-plugin  deepseek-harness  token  cost  billing  qwen  bailian  usage  dashboard
  ```

**② 确认 README 显示正常**

首页往下拉，应该能看到你的 README（标题、表格、代码块都在）。如果显示的是文件名而不是内容，说明文件名大小写不对，必须是 `README.md`。

### 4.4 以后每次改完代码怎么上传

GitHub Desktop 的日常循环只有三步：

1. 左下角填 **Summary**（一句话说明改了什么，比如 `fix: 修正缓存价计算`）
2. 点 **`Commit to main`**
3. 点右上角 **`Push origin`**（把本地提交推到 GitHub）

三个按钮的区别，记住这一句就够：

| 按钮 | 方向 | 干什么 |
|---|---|---|
| `Fetch origin` | 只问不拿 | 看看远端有没有新东西 |
| `Pull origin` | 远端 → 本地 | 把别人/网页上的改动拉下来 |
| `Push origin` | 本地 → 远端 | 把你的提交推上去 |

## 5. 发布到 npm（商场能搜到的前提）

### 5.1 先解决 PowerShell 的脚本限制（一定会踩）

如果你在 PowerShell 里敲 `npm` 报这个错：

```
无法加载文件 C:\Program Files\nodejs\npm.ps1，因为在此系统上禁止运行脚本
```

二选一：

**方案 A（推荐，一次搞定）**

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

出现提示输 `Y` 回车。这是 Windows 的标准安全设置，只影响当前用户。

**方案 B（不改系统设置）**

以后一律用 `npm.cmd` 代替 `npm`：

```powershell
npm.cmd test
npm.cmd publish
```

### 5.2 登录 npm

```powershell
npm login
```

会跳出浏览器让你授权，授权完回到 PowerShell 显示 `Logged in as 你的用户名`。

验证：

```powershell
npm whoami
```

打印出来的名字必须和包名的 `@` 后面那段**完全一致**。不一致就说明作用域不属于你，`npm publish` 会报 404。

### 5.3 发布

```powershell
npm publish
```

- 会自动先跑 `npm run check` + `npm test`，任何一项失败都会中止发布（这是好事，防止把算错钱的版本发出去）
- 大约十几秒，成功会打印：

```
+ @looriann/dsh-cost-ledger@0.1.0
```

### 5.4 验证发布成功

```powershell
npm view @looriann/dsh-cost-ledger version
```

打印 `0.1.0` 就成了。再去 <https://www.npmjs.com/package/@looriann/dsh-cost-ledger> 看页面，README 会自动显示成包主页。

### 5.5 常见报错对照表

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `E404 Not Found - PUT .../@你的名字%2f...` | 作用域不属于你，或用户名写错 | 跑 `npm whoami` 核对，用 `npm run rename` 改成正确的 |
| `E403 You do not have permission to publish` | 这个名字已存在 | 换个后缀，如 `-cn`，然后重新 rename |
| `E402 Payment Required` / 要求 OTP | 账号开了两步验证 | 命令行提示时输入验证器里的 6 位码，或加 `--otp=123456` |
| `ENEEDAUTH` | 没登录 | `npm login` |
| `EPERM ... npm-cache` | 权限/杀软拦截 | 换 `npm.cmd`，或加 `--cache .npm-cache` |
| 发布成功但商场搜不到 | 索引有延迟 | 等几分钟；确认 `package.json` 里有 `"dsh"` 字段 |

## 6. 让插件出现在商场里

商场的索引通常来自 npm 上带 `dsh` 标记的包，所以：

1. **先确保第 5 节发布成功**
2. 打开你的商场页面，找「提交插件 / 上传插件 / 添加仓库」之类的入口
3. 需要填地址时，填 `https://github.com/你的账号/dsh-cost-ledger`
4. 第一次收录可能要人工审核，等一会儿

如果你不确定入口在哪，就去商场里搜一个你已经装过的插件（比如 `dsh-context`），看它的详情页有没有「查看源码 / 提交」按钮，跟着学。

## 7. 以后发新版本

改完代码 → 升版本号 → 提交 → 推送 → 发布：

```powershell
npm version patch        # 0.1.0 → 0.1.1（修 bug）；新功能用 minor，大改版用 major
```

这会把 `package.json` 的版本号改掉并自动打一个 git commit。然后：

```powershell
# GitHub Desktop 里点 Push origin
npm publish
```

顺手在 `CHANGELOG.md` 顶上补一段这次改了什么。
